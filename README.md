### External resources

This project requires pretrained embeddings:

- FastText cc.en.300.bin  
  Download: https://fasttext.cc/docs/en/crawl-vectors.html

- GloVe glove.840B.300d.txt
  Download: https://nlp.stanford.edu/projects/glove/
  
Place the file at:
model/fasttext/cc.en.300.bin
model/glove/glove.840B.300d.txt
